## 何ができるもの？

紙で管理している「今日どのメニューを誰が施術したか」と「日払い（歩合）計算」を、入力→自動計算→日次集計→支払い済み更新→CSV出力まで一元化する **MVP（最小実用版）** です。

- **施術の入力**: 日付・セラピスト・メニュー・数量を入力して記録
- **日次集計**: 売上合計 / 支払い合計（歩合）を自動計算し、支払い済み更新も可能
- **マスタ管理**: セラピスト / メニュー（価格・歩合ルール）を登録・更新
- **CSV出力**: 期間指定で記録をCSVダウンロード

## 仕様（歩合計算）

メニューごとに以下を設定できます。

- **固定(円)**: 例）延長 10分 → 1件あたり 500円
- **％(売上に対して)**: 例）もみほぐし 60分 → 売上の 60%

セラピスト側には **歩合倍率**（例: 1.0 / 1.1）も持たせています（必要ない場合は 1.0 のままでOK）。

## 起動方法（ローカル）

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit_app.py
```

起動すると `data/salon.db`（SQLite）が自動作成されます。

## データの場所

- `data/salon.db`: SQLiteのDBファイル（このファイルをバックアップすればデータ保全できます）
