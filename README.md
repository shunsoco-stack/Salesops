## 売上・客数管理（ローカル版 / 案A）

Excelで管理していた「売上・客数」等を、**PC内で完結する小型アプリ**（ブラウザで入力・一覧・月次集計・CSV出力）として運用できます。

### できること
- **入力**: 発生日, 売上, 客数, 客単価(自動計算), 外注費（合計）, 外注費内訳（任意）, 利用ポイント, 店舗売上, 現金決済, カード決済, QR決済, 備考
- **一覧**: 月ごとの表示、編集、削除
- **集計**: 月次の合計/平均（売上合計、客数合計、客単価、決済別合計など）
- **CSV出力**: 月次データをCSVでダウンロード

### データ保存場所
- `data/sales.db`（SQLiteの1ファイルDB）
  - バックアップはこのファイルをコピーするだけでOKです。

### 起動手順（Linux / bash）
Python 3.11+ を想定しています（この環境では `python3` を使用）。

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

起動後、ブラウザで `http://127.0.0.1:8000` を開いてください。

### 使い方
- 画面上部のフォームに入力して「保存」
  - 同じ発生日が既にある場合は**上書き更新**します
- 月を変える: 右上の「対象月」で切替
- CSV: 「CSV出力」から月次CSVを取得

### 注意
- 「客単価」は `売上 / 客数` を自動計算（客数=0のときは空）します
- 「外注費内訳」を入れた場合は、内訳の合計を自動計算して「外注費（合計）」として保存します（例: `10000+5000+5000` または 1行ずつ金額のみ）
- 「店舗売上」は `売上 - 外注費` を自動計算します（入力不要）
- 「現金決済」は `売上 - 利用ポイント - カード決済 - QR決済` を自動計算します（入力不要）
- カード決済/QR決済はCSV取り込みに対応しています（ヘッダー例: `発生日,カード決済,QR決済`）
- 以前あった「店舗売上」と「現金+カード+QR」の一致チェックは、店舗売上/現金決済が自動計算になったため不要になりました
