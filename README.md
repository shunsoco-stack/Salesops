## リラクゼーションサロン：施術入力＆日払い計算（iPadブラウザ対応）

### できること
- **施術入力（iPad/スマホ/PCのブラウザ）**
  - **メニューをプルダウン選択** → **施術料を自動表示**
  - **日払い（取り分）**を自動計算して表示（初期値：50%）
  - 1日あたり **3〜7件**程度の入力に対応（1件ずつ「追加」）
  - **売上合計** と **日払い合計** をその場で表示
- **管理（オーナー/受付）**
  - メニューの **追加・値上げ・取り分(%)変更・無効化**
  - セラピストの **追加・無効化**
- **重要**: 過去の入力は **スナップショット保存**なので、メニュー価格や取り分を後から変えても **過去の支払額は変わりません**。

### 初回メニュー
`data/initial_menus.csv` を起動時に自動取り込みします（DBが空のときのみ）。

### 起動方法
Python 3.12+ が必要です（標準ライブラリのみ使用、追加インストール不要）。

```bash
python3 /workspace/app.py
```

起動後:
- 入力画面: `http://localhost:8000/`
- 管理画面: `http://localhost:8000/admin`

### DBファイル
- 既定: `./salon.db`
- 変更したい場合:

```bash
SALON_DB=/workspace/salon.db python3 /workspace/app.py
```

### 注意（社内LANでiPadから開く）
サーバーを動かしているPCとiPadが同じWi‑Fi/LANにいる場合、iPadからは `http://localhost:8000` ではなく、
サーバーPCのIP（例：`http://192.168.1.10:8000`）で開いてください。
